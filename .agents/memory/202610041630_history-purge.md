# History purge: Airtable export and superseded data versions

Date: 2026-10-04 (executed on explicit developer instruction:
"hard delete places.eml and all older versions of .ttl files from the
git repo, local and origin")

## What was done

- `data/import/places.eml` deleted from the working tree and excluded
  from the repository permanently. It contains non-public records
  (private homes); regeneration now requires supplying it manually
  from Airtable.
- Eml-dependent tests rewritten against a synthetic fixture
  (`tests/fixtures/mini-places.eml`, 8 records covering venue,
  group, private, and placeholder categories). Full pipeline coverage
  is retained without the real export.
- Git history restarted from a single fresh root commit. The previous
  history (2 commits) contained the eml and all 200 superseded .ttl
  versions including `private-home-*`, `ktgr-*`, and `place-l*`
  files. Old objects were expired from the local reflog and pruned,
  and the rewritten `main` was force-pushed to origin.

## Open items

- `data/import/places-enrichment.json` and `places-curation.json`
  still contain municipality-level entries for the non-published
  records (e.g. `private-home-hantum`). Not part of the requested
  purge; flag to the developer whether to scrub those too.
- GitHub may serve the old commits from cache for a while (they are
  unreachable but not instantly gone server-side). If the repo was
  public and the eml must be unretrievable, contact GitHub support to
  purge cached views; any pre-rewrite clones retain the data.

## Follow-up: import caches purged too

On the same instruction, `places-enrichment.json` and
`places-curation.json` were also removed from the tree and history.
Before purging, both were backed up (the curation layer is
irreplaceable reviewed work) to
`../master-library-lod-private-import/` (outside any git repo), with a
README explaining what they are. The root commit was amended to
exclude them and force-pushed; local objects pruned. `propose` now
warns and emits no proposals when the curation file is absent.
